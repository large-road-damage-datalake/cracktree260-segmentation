# CrackTree260

## Overview

CrackTree260 is a pavement crack segmentation subset released with the DeepCrack benchmark (expanding the earlier CrackTree206 predecessor lineage from Zou et al. 2012).

- Task: segmentation
- Images: 260
- Annotations: 1231
- Classes: 1 (crack)
- Annotation format: paired bitmap masks

The dataset contains 260 top-down area-array pavement images (206 at `800x600` and 54 at `960x720`) captured under visible-light illumination.
